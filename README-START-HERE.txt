1. Download advisor-ai-website-upgrade.zip to your Mac's Downloads folder.
2. Open Terminal.
3. Paste this one line and press Enter:

cd ~/advisor-ai-blueprint && unzip -o ~/Downloads/advisor-ai-website-upgrade.zip

4. Open the advisor-ai-blueprint folder in VS Code.
5. If you want to preview, type in Terminal: npm run dev
   (Open http://localhost:5173; stop with Control+C.)
6. Open GitHub Desktop and select the advisor-ai-blueprint repository.
7. You should see changed files. Type 'Finish advisor AI website' into Summary,
   then click Commit to main, then Push origin.
8. Vercel automatically redeploys your existing website after the push.
